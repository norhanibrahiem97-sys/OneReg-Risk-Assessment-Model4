Load a OneReg export

In deployment the model reads consignments directly from OneReg's records. Loading a file here stands in for that connection, and lets the model be run against any other dataset. Column names are matched against the same alternatives the Python engine's column map uses, so an export does not have to be renamed. Fields the file does not carry stay missing and leave the score unchanged.

Drop an .xlsx or .csv here, or click to choose a file Everything is parsed in your browser. No file is uploaded anywhere, which matters for commercially sensitive shipment records.

Add a variable to the model

The model reads its variables from configuration, not from code, so a new evidence stream can be added without touching the engine. This is the same operation as adding an entry to model_config.json in the Python package.
